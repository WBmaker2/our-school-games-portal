# 우리학교 벽돌 격파왕 (OUR SCHOOL BRICK BREAKER)

우리학교 게임 포털을 위해 설계된 **고성능 2D HTML5 Canvas 기반의 클래식 블록 격파 아케이드 게임** 모듈입니다.

---

## 📁 디렉터리 구성

```
src/components/games/brickbreaker/
├── BrickBreakerGame.jsx             # 메인 리액트 컴포넌트, 캔버스 마운트, 게임루프, 랭킹 등록
├── BrickBreakerHowToPlayModal.jsx   # 게임 방법 및 4종 특수 블록 & 7종 파워업 아이템 도감 모달
├── brickBreakerPhysics.js          # 공-패들-벽돌 충돌 연산, 반사각 계산, 파티클 및 캡슐 아이템 물리
├── brickBreakerConstants.js        # 스테이지 맵 데이터(1~5단계), 블록 타입/색상, 파워업 정의
├── brickBreakerAudio.js            # Web Audio API 기반 아케이드 신디사이저
├── brickbreaker.css                # 네온 아케이드 테마, 글래스모피즘 HUD, 모바일 컨트롤러 스타일
└── README.md                       # 아키텍처 및 상세 사양 문서
```

## ✨ 핵심 기능 및 특징

1. **초정밀 반사 물리 연산**:
   - 패들의 타격 위치(중심 vs 가장자리)에 따른 연속적 각도 반사 ($-60^\circ \sim +60^\circ$)
   - AABB 원-박스 충돌 판정 및 침투 깊이 반사 보정으로 벽돌 관통 끼임 버그 원천 차단
2. **다채로운 5단계 스테이지 맵**:
   - 스테이지 1: 우리학교 클래식 무지개
   - 스테이지 2: 우리학교 사랑의 하트
   - 스테이지 3: 다이아몬드 철갑 요새
   - 스테이지 4: 우주 침공 인베이더
   - 스테이지 5: 우리학교 대마왕 최종 관문
3. **특수 블록 & 7종 파워업 아이템**:
   - 일반, 2~3HP 강화 블록(균열 표시), 3x3 연쇄 폭탄 블록, 보너스 스타 블록
   - 멀티볼(3구 복제), 와이드 패들, 레이저 캐논, 관통 파이어볼, 바닥 방어막, 슬로우 모션, 생명 보너스
4. **Web Audio API 신디사이저**:
   - 연속 벽돌 격파 시 C 메이저 펜타토닉 음계가 실시간으로 상승하는 콤보 하모니
   - 레이저 발사, 폭발음, 파워업 획득음, 클리어 팡파레
5. **PC & 모바일 완전 대응**:
   - 마우스 이동 & 키보드(← / → / Space) 조작
   - 모바일 터치 드래그 & 온스크린 방향키 + 액션 버튼
6. **우리학교 명예의 전당 연동**:
   - 100점 초과 달성 시 점수 등록 입력창 노출 (힌트: `'예: 홍길동'`)
   - 점수 등록 시 리더보드 모달의 `brickbreaker` 탭 자동 활성화

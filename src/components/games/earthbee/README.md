# 🐝 우리학교 꿀벌의 비행 (Earth Day Bee 모티브)

구글 2020년 지구의 날(Earth Day 50주년) 인터랙티브 두들을 모티브로 제작된 우리학교 전용 **힐링 비행 액션 아케이드 게임**입니다.

---

## 📁 파일 구조 (독립 폴더 관리)
- `EarthBeeGame.jsx`: 메인 게임 컨트롤러, HUD 상태 관리, 타이머, 리더보드 점수 등록 UI
- `earthBeeEngine.js`: 60FPS Canvas 2D 고해상도 물리 & 수분/개화 파티클 렌더링 엔진
- `earthBeeAudio.js`: Web Audio API 기반 비행 허밍, 꽃가루 챠임, 개화 팝 신디사이저
- `earthBeeConstants.js`: 꽃 종류, 생태계 레벨, 배점, 교육적 환경 팩트 메시지 정의
- `EarthBeeHowToPlayModal.jsx`: 게임 방법 및 조작법 팝업 모달
- `earthbee.css`: 반응형 꿀벌 테마 스타일시트
- `README.md`: 프로젝트 구조 및 기능 명세서

---

## 🎮 게임 규칙 및 시스템
1. **꿀벌 비행 조작**: 마우스 포인터, 모바일 터치 드래그, 키보드 방향키(WASD / 화살표) 완벽 지원
2. **꽃가루 수분(Pollination)**:
   - 만개한 꽃 근처로 비행하여 꽃가루를 충전
   - 꽃봉오리에 다가가 꽃가루를 전달하면 꽃이 활짝 피어남(Bloom)
3. **콤보 및 시간 보너스**:
   - 연속으로 꽃을 피우면 콤보 배수(최대 x5) 및 추가 생존 시간(+초) 획득
4. **우리학교 생태계 정원 레벨**:
   - 누적 개화 수에 따라 화단이 번성하며 신비한 무지개 꽃 및 다채로운 나비들이 등장
5. **명예의 전당 등록 규칙**:
   - `score > 100`점 초과 달성 시에만 점수 등록 폼 노출
   - 입력창 placeholder: `'예: 홍길동'`
   - 등록 완료 시 리더보드 '우리학교 꿀벌의 비행' 탭 자동 선택

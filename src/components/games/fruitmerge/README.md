# 우리학교 과일 합치기 (Our School Fruit Merge / 수박게임)

## 📌 게임 개요
* **게임명**: 우리학교 과일 합치기 (Our School Fruit Merge)
* **장르**: 2D 물리 엔진 기반 실시간 드롭 & 합성 캐주얼 퍼즐
* **카테고리**: 퍼즐 / 16호 게임
* **주요 목표**: 상단 크레인에서 떨어지는 과일을 좌우로 조준해 투하하고, 동일한 과일 2개가 충돌하면 다음 상위 단계 과일로 합성시켜 최종 목표인 **'대왕 수박🍉'**을 완성하는 게임입니다.

---

1. 🍒 **체리** (Level 0) ➔ 2점

3. 🍇 **포도** (Level 2) ➔ 8점
4. 🍊 **한라봉/귤** (Level 3) ➔ 16점
5. 🍅 **감/토마토** (Level 4) ➔ 32점
6. 🍎 **사과** (Level 5) ➔ 64점
7. 🍐 **배** (Level 6) ➔ 128점
8. 🍑 **복숭아** (Level 7) ➔ 256점
9. 🍍 **파인애플** (Level 8) ➔ 512점
10. 🍈 **멜론** (Level 9) ➔ 1,024점
11. 🍉 **대왕 수박** (Level 10) ➔ 2,048점 (대합성 팡파레!)

## 🎯 주요 기능 및 시스템
* **6단계 서브스텝 물리 적분 연산**: 과일들이 겹치거나 튕겨 나가지 않도록 정밀한 원형 충돌 및 마찰력 계산.
* **스쿼시 & 스트레치 (Squash & Stretch) 쫀득한 탄성 변형**: 과일이 충돌할 때 자연스럽게 찌그러졌다가 펴지는 젤리 탄성 애니메이션.
* **표정 렌더링**: 눈 깜빡임(Blink), 입 모양 등 귀여운 표정 프로시저럴 드로잉.
* **비상 상자 흔들기 (Shake Chance)**: 과일이 구석에 끼었을 때 흔들어 탈출시키는 비상 스킬 2회 제공.
* **우리학교 명예의 전당 연동**: 100점 초과 득점 시 실시간 전교 랭킹 등록 및 자동 탭 동기화.

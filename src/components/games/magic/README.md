# 우리학교 매직 캣 아카데미 (Our School Magic Cat Academy)

구글 할로윈 인터랙티브 두들 명작 **Magic Cat Academy (마법 고양이 모모)**를 우리학교 게임 포털을 위해 재해석 및 구현한 드로잉 제스처 기반 마법 액션 게임입니다.

---

## 🎮 1. 게임 개요
* **장르**: 2D 제스처 드로잉 마법 액션 아케이드
* **주인공**: 마법학교 신입생 검은 고양이 **모모(Momo)**
* **스토리**: 마법학교의 대마법서(*Master Spellbook*)를 도둑맞아 침공한 유령 군단에 맞서 마법 지팡이를 들고 5대 마법학교 테마 스테이지를 돌파하여 학교의 평화를 되찾는 모험.

---

## 🪄 2. 6대 마법 주문 심볼 & 제스처 인식 알고리즘
* **가로선 (`—` / HORIZONTAL)**: 가로 방향 선 긋기
* **세로선 (`│` / VERTICAL)**: 세로 방향 선 긋기
* **산 모양 (`∧` / UP_V)**: 위로 솟았다가 내려오는 산 모양
* **골 모양 (`∨` / DOWN_V)**: 아래로 내려갔다가 올라오는 골 모양
* **번개 (`⚡` / LIGHTNING)**: 지그재그 제스처로 화면 내 동일 기호 유령 동시 광역 타격
* **하트 (`❤️` / HEART)**: 하트 형태 드로잉으로 잃어버린 생명력(+1 HP) 회복

---

## 🏰 3. 5대 마법학교 테마 스테이지
1. **1단계: 고요한 도서관 (Library)** - 단일 기본 기호 (`—`, `│`) 훈련
2. **2단계: 어수선한 식당 (Cafeteria)** - 복합 기호 (`∧`, `∨`) 및 고속 유령
3. **3단계: 신비한 마법 교실 (Classroom)** - 3단 복합 기호 + 번개 광역 마법
4. **4단계: 밤의 체육관 (Gym)** - 다방면 대규모 유령 군단 침공
5. **5단계: 폭풍우 치는 옥상 (Rooftop Boss)** - 대마법서 거대 보스 악령과의 최종 결전

---

## 🛠️ 4. 기술 아키텍처
* **`MagicCatGame.jsx`**: 메인 리액트 래퍼, HUD, 게임오버/승리 모달, 랭킹 등록
* **`magicLogic.js`**: 60FPS Canvas 2D 렌더링, 모모/유령/보스 물리 및 파티클 연출
* **`magicRecognizer.js`**: 마우스 & 터치 드로잉 기하학적 제스처 판정 엔진
* **`magicAudio.js`**: Web Audio API 기반 마법 효과음 및 승리 팡파르 합성기
* **`magicConstants.js`**: 스테이지 및 심볼 상수 데이터
* **`magic.css`**: 마법 테마 네온 글로우 스타일링

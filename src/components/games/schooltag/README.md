# 🔦 우리학교 야간 학교 숨바꼭질 (School Tag)

불 꺼진 야간 우리학교 본관/신관을 무대로 펼쳐지는 **2D 탑다운 비대칭 실시간 술래잡기(Asymmetric Survival Tag)** 게임입니다.

---

## 1. 주요 특징 및 기술 스택
- **2D Fog of War (전장의 안개) & 레이캐스팅 조명**:
  - 플레이어가 바라보는 방향으로만 부채꼴 형태의 손전등 빛(75도)이 비춰지며, 교실 벽/사물 뒤편에는 실시간 그림자가 생성됩니다.
  - 술래는 붉은 안광과 붉은 손전등(110도)을 지니고 있어 다가올 때 벽면에 붉은 기운이 반사됩니다.
- **Web Audio API 절차적 음향 합성 엔진**:
  - 외부 오디오 파일 다운로드 0% (로딩 지연 및 CORS 오류 원천 차단).
  - 술래와의 거리에 따라 박동 주기와 볼륨이 실시간으로 변하는 심장 박동음, 손전등 스위치, 발자국 소리, 황금 열쇠 획득 징글, 비상구 사이렌 등을 탑재.
- **초경량 WebRTC P2P 멀티플레이어 (PeerJS)**:
  - 4자리 숫자 방 코드 기반으로 렉 없는 P2P 실시간 좌표 동기화 지원.
  - Fog of War가 시야 밖 네트워크 레이턴시를 자연스럽게 가려주어 저사양 PC/크롬북에서도 부드러운 60fps 보장.
- **스마트 AI 술래 (솔로 모드)**:
  - 혼자서도 즐길 수 있도록 순찰(Patrol) ➔ 소음 조사(Investigate) ➔ 전력 추격(Chase) 상태 머신을 갖춘 AI 당직선생님 봇 탑재.

---

## 2. 파일 구성
- `SchoolTagGame.jsx`: 메인 게임 래퍼, 캔버스 렌더링 루프, HUD, 모바일 컨트롤러, 게임오버 및 명예의 전당 점수 등록
- `SchoolTagHowToPlayModal.jsx`: 조작법 및 생존 수칙 안내 모달
- `schoolTagConstants.js`: 타일 크기, 시야각/거리, 스태미너, 점수 산출 상수, P2P 설정
- `schoolTagAudio.js`: Web Audio API 신디사이저 엔진
- `schoolTagMap.js`: 우리학교 교실/복도 그리드 맵 및 벽 세그먼트 생성기
- `schoolTagLogic.js`: 2D 레이캐스팅 광선 계산, 벽 충돌, 스마트 AI 상태머신, 점수 산출 로직
- `schoolTagNetwork.js`: PeerJS P2P 룸 생성 및 데이터 동기화 매니저
- `schooltag.css`: 다크 호러 아케이드 네온 테마 및 반응형 레이아웃

---

## 3. 포털 전역 규칙 준수 사항
- **독립 폴더 관리 원칙**: 모든 모듈이 `src/components/games/schooltag/` 내에 완전히 독립적으로 구성됨.
- **명예의 전당 입력창 placeholder**: `'예: 홍길동'`으로 통일 적용.
- **100점 이하 점수 등록 차단 원칙**: `finalScore <= 100`인 경우 점수 등록 폼 미노출.
- **점수 등록 후 리더보드 자동 동기화**: 점수 등록 완료 시 `onScoreSubmitted()`를 통해 리더보드 모달의 `schooltag` 탭 자동 활성화.
